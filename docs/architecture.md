# 架构

React + TypeScript + Vite 构成前端，Zustand 管理状态；Cloudflare Worker 提供静态资源和同源代理，无常驻业务后端。

## 模块职责

| 位置                                                   | 职责                                                            |
| ------------------------------------------------------ | --------------------------------------------------------------- |
| [types.ts](../src/types.ts)                            | 领域数据契约                                                    |
| [providers](../src/providers)                          | 接口适配、能力归一化与请求校验；配置维护见[模型文档](models.md) |
| [store](../src/store)                                  | 领域操作、供应商与任务状态、持久化协调                          |
| [lib](../src/lib)                                      | 存储、迁移、素材规则等窄职责逻辑                                |
| [agent](../src/agent)                                  | 通过统一适配器执行对话与工具调用                                |
| [views](../src/views)、[components](../src/components) | 页面组织与局部交互                                              |
| [worker](../worker)                                    | 无状态代理与静态资源入口                                        |

## 数据边界

- 供应商实例与接口协议分开；连接元数据不含 Key，运行配置按连接绑定凭据。模型请求使用服务商原始 ID，显示名称不参与能力判断。
- 保存供应商时，Key 写入当前浏览器 localStorage；旧 sessionStorage 凭据仍可读取，再次保存该供应商后转为长期保存。Worker 不持久化 Key。
- 能力声明与生成参数分开；发现、手动配置、历史恢复和请求发送前均需约束能力，旧缓存不能绕过当前限制。
- Studio 与 Chat 草稿的附件引用独立，图片与视频创作草稿分别保留。解除素材引用不等于删除资产；删除会话保留作品，资产的会话引用允许悬空。
- 持久化与迁移入口在 [storage.ts](../src/lib/storage.ts) 和 [migration.ts](../src/lib/migration.ts)。读库失败不作为空库启动；普通自动保存尚未统一提供写入失败恢复提示，内存更新不代表落盘成功。
- `imageEditing` 与 `image.supportsEdit` 是历史兼容镜像，写入与恢复保持一致。其他字段直接查类型，不维护第二套字典。

## 视频任务

[videoTasks.ts](../src/store/videoTasks.ts) 管理提交、轮询、取消和恢复，不依赖页面组件生命周期。

- 创建远端任务前先保存本地记录；记录保存模型与连接地址快照，不保存 Key。
- 提交结果不明时不自动重建任务，允许补充远端任务编号恢复查询；查询错误不覆盖生成状态，凭据或连接变化时暂停查询。
- 页面隐藏或离线时暂停查询；重新打开后按记录恢复。删除会话不取消后台任务，删除任务卡不删除作品。
- 视频作品与任务的已保存标记在同一事务写入；作品保存上游链接，不等于已离线保存视频。
- 取消前检查远端排队状态，取消后查询确认；上游缺少原子条件取消，仍存在状态变化窗口。

## 网络边界

同源代理只接受白名单 HTTPS 主机，拒绝上游重定向；DELETE 仅允许方舟视频任务路径。自定义网关走直连，媒体下载不携带 API Key，不提供任意媒体代理。路由和发布方式见[部署](deployment.md)。
